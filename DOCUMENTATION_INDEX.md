## 📋 Quick Navigation

### Files to Edit First
- `backend/.env` - Set MongoDB URI and JWT secret
- `frontend/.env` - Set API URL (usually already configured)

### Scripts to Run
```bash
# One-time setup (from project root)
python3 setup.py

# Or manual setup
cd backend && npm install && node _setup.js
cd ../frontend && npm install && python3 setup_frontend.py

# To run the application (3 terminals)
mongod                    # Terminal 1
cd backend && npm run dev # Terminal 2
cd frontend && npm run dev # Terminal 3
```

### Access Points
- Frontend: http://localhost:5173
- Backend: http://localhost:5000
- API: http://localhost:5000/api
